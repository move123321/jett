# 원본 보존 파츠 보완 + 동작 확인

## 바로 사용하기

1. `동작_확인.html`을 Chrome 또는 Edge에서 연다. 인터넷 연결 없이 동작한다.
2. 눈 열림, 시선, 입 열림, 눈썹 슬라이더를 움직인다. 자동 깜빡임과 머리·후드 흔들림도 켤 수 있다.
3. 오디오 립싱크를 펼쳐 음성 파일을 선택하면 음량에 맞춰 입이 움직인다. 마이크는 버튼을 누르고 브라우저 권한을 허용해야 켜진다. 녹음·업로드 기능은 없고 브라우저에서만 음량을 분석한다.
4. `원본 자세로 초기화`를 누르면 모든 움직임과 오디오 분석을 멈추고 원본 모습으로 돌아온다. `누르는 동안 원본 보기`로 비교한다.

## 실제 파일

- `Jett_restored_motion_layers.psd`: 배경 포함 **52개 비어 있지 않은 레이어**. 원본의 보이는 픽셀과 보완 그림을 분리해 편집할 수 있다.
- `Jett_Cubism_import_art.psd`: 배경을 제외한 **51개 레이어**의 가져오기용 원화 초안. Cubism에서 실제 열기 검증은 아직 하지 않았다.
- `parts/`: 같은 341×361 캔버스에 정렬한 원본 파츠, 보완 파츠, 눈 클리핑용 마스크 PNG.
- `neutral_exact.png`: 보완 PSD의 기본 합성 결과. **원본 RGBA 픽셀과 동일**하다.
- `character_transparent.png`: 배경을 제외한 합성. 외곽의 배경색 잔여 픽셀과 잘린 머리 상단은 추가 정리 대상이다.
- `layers.json`, `cubism_art_layers.json`: 수정 가능한 레이어 명세. 순서는 아래→위다.
- `동작_확인.html`: 별도 설치 없이 실행하는 브라우저용 2D 파츠 리그. 외부 라이브러리나 서버가 필요 없다.
- `psd_verification.json`, `browser_verification.json`: 실제 파일·브라우저 검증 결과.

## 이번에 보완한 내용

기존 분리본에서 배경에 남아 있던 머리·몸통 경계 픽셀을 별도 파츠로 옮겼다. 눈을 감거나 입을 열 때 원래 눈 선·입 선이 남지 않도록 주변 잔여 픽셀도 별도 문맥 레이어로 분리했다. 이렇게 정리한 원본 픽셀 레이어 45개에 보완 레이어 7개를 추가했다.

보완 레이어는 피부, 머리 안쪽 겹침, 좌우 흰자, 입안, 윗니, 혀다. 피부·흰자·입안 원화는 내장 이미지 편집 도구로 생성했고, 원본 위에 덮지 않고 숨은 영역에 사용한다. 머리 겹침은 원본 머리 픽셀을 안쪽 보조 영역에 사용했다. 원본 머리·눈·입·피부의 보이는 부분은 재작화하지 않았다. 기본 상태의 PSD와 브라우저 화면 모두 원본과 픽셀까지 같다.

## 구현된 움직임과 한계

| 항목 | 현재 구현 |
|---|---|
| 눈 깜빡임 | 좌우 독립 열림, 자동 깜빡임. 피부 보완 위에서 원본 속눈썹 파츠를 변형 |
| 시선 XY | 눈 내부 마스크로 잘라낸 홍채·동공·반사 이동 |
| 입 | 원본 입술과 보완 입안·윗니·혀를 이용한 열림. 입 모양은 작은 가로 변형 |
| 립싱크 | 음량 기반 입 열림. 브라우저 오디오 파일 입력으로 실제 테스트함. 음소별 입 모양 인식은 아님 |
| 눈썹 | 원본 눈썹의 좌우 독립 상하 이동 |
| 고개 XYZ | 원본 인상을 보존하는 작은 2D 이동·축소·기울기 근사. 9방향 원근 키폼은 아직 아님 |
| 몸통 | 작은 Z 기울기와 선택적 미세 호흡 |
| 머리·후드 | 감쇠 진동으로 작은 지연 흔들림. 정지 후 수렴 테스트 통과 |

**브라우저 동작 확인 파일은 Cubism 런타임이나 `.moc3`가 아니다.** 브라우저의 움직임이 PSD에 리깅 데이터로 저장되어 있는 것도 아니다. 실제 Live2D 모델로 쓰려면 Cubism에서 메시, 디포머, 키폼, 물리를 만들고 내보내야 한다. 설치된 Cubism 실행 환경은 이번 점검에서 확인하지 못했다.

현재는 341×361px 원본 안에 보이는 머리·얼굴·목·후드 범위다. 원본에 없는 팔·손·몸통 하단·어깨장식 전체는 임의로 추가하지 않았다. 블렌더 전신 자료는 구조 참고로 보존했으며, 원본 일러스트를 바꾸지 않기 위해 이번 원화로 대체하지 않았다.

큰 고개 움직임에서는 잘린 상단·옆머리 외곽·일부 파츠 경계가 드러난다. 파츠 겹침 보완이 모든 각도의 숨은 영역을 완성한 것은 아니다. 낮은 해상도 때문에 눈·입의 중간 변형에서도 경계가 눈에 띌 수 있다. 표정 완성도와 큰 회전은 고해상도 원본 또는 추가 원화 작업이 필요하다.

## 검증한 범위

PSD를 별도 파서로 열어 모든 레이어가 비어 있지 않고 개별 PNG와 일치함을 확인했다. 레이어를 다시 합친 결과도 저장된 미리보기와 일치했다. 배경 포함 기본 합성은 원본과 RGBA 픽셀까지 같다.

Chrome에서 초기 화면의 원본 일치, 눈 감기·시선·입 열림·복합 조작, 흔들림 안정화, 음성 입력 경로에 테스트 신호를 넣었을 때 입 열림 반응, 설정 파일 저장을 확인했다. JavaScript 오류는 없었다. 실제 마이크 장치와 Cubism 가져오기/내보내기는 테스트하지 않았다.

기존 `리깅_준비_가이드.md`의 Cubism 제작 계획은 그대로 후속 제작 명세로 사용할 수 있다. 이번 `현재 값 저장` 결과는 이 브라우저 리그의 설정 JSON이며 Cubism 설정 파일이 아니다.
