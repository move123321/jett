# Live2D 리깅 준비 — 원본 보존 설계

## 산출물 상태

첫 번째 첨부 이미지(341 × 361px)를 기준으로 설계했다. 두 번째 정면 변환 이미지는 형태 기준으로 사용하지 않았다. `Live2D_structure_TEMPLATE.psd`는 원본 참조 이미지와 빈 파츠 레이어를 가진 편집용 구조 템플릿이다. 실제 파츠 그림의 분리, 가려진 영역 복원, 메시 생성, 키폼, 물리 설정은 아직 적용되지 않았다. `.cmo3`, `.moc3`, `.physics3.json` 완성 파일이 아니다.

원본 전체 그림을 하나의 참조 레이어로 보존했다. 배경·우측의 일부 물체·상단 잘린 영역도 원본 그대로다. 따라서 이 참조 레이어를 모델 파츠로 가져오면 안 된다. 모든 파츠 슬롯은 투명하며, Cubism에 바로 넣어 리깅할 수 있는 그림 데이터는 아직 없다. 캔버스는 원본 크기를 유지했다. 고해상도 원본이 확보되면 원본 비율을 유지한 제작 캔버스로 옮겨 작업한다. 확대만으로 세부 묘사가 복구되지는 않는다.

## 디자인 고정 기준

- 원본의 얼굴 폭, 볼에서 턱으로 이어지는 곡선, 눈 사이 간격, 눈꼬리와 속눈썹 각도를 유지한다. 원본에 있는 좌우 차이를 자동 대칭으로 지우지 않는다.
- 회청색 홍채, 흰색·연보라 음영의 머리, 피부 및 입술 색, 남색 후드 색을 원본에서 직접 채집한다. 별도 필터나 재색칠로 색조를 바꾸지 않는다.
- 중앙으로 내려오는 앞머리, 좌우 긴 옆머리, 위로 묶인 머리의 큰 실루엣을 유지한다. 슬롯 개수에 맞추려고 새 머리카락 가닥을 추가하지 않는다.
- 귀·이마·턱·목의 비율과 후드 테두리를 기준점으로 삼는다. 원본의 자세를 중립 형태로 두는 작은 움직임부터 제작한다. 정면 재구성은 별도 그림 작업이므로 자동으로 정면화하지 않는다.
- 묶음머리 위쪽, 몸통, 팔, 의상 하단, 어깨장식의 전체 디자인은 현재 이미지에 없다. 미확인 형태를 새로 디자인하지 않는다. 우측 가장자리 물체도 정체가 확인되지 않았다.

## 레이어 규칙 및 PSD 사용

`layer_manifest.json`은 수정 가능한 전체 레이어 명세다. 그룹과 레이어 목록은 위에서 아래의 표시 순서를 뜻한다. 최종 겹침은 복원한 그림에 맞춰 검토한다. PSD 폴더 순서는 그리기 순서의 초안이며 Cubism 디포머 부모 관계와는 별개다.

L/R는 **캐릭터 기준**이다. L은 화면 오른쪽, R은 화면 왼쪽이다. 모든 파츠 이름은 유일하며 영문 밑줄을 사용한다. `_01` 등은 독립적으로 움직일 덩어리의 번호다. 하나의 가닥을 뿌리와 끝으로 나눌 필요가 없다면 단일 레이어와 여러 디포머로 구현해도 된다. `PENDING` 그룹은 디자인 확인 전의 자리다.

PSD를 열어 참조 레이어를 잠근 뒤 파츠 슬롯에 그림을 넣는다. 레이어 이름을 유지하고, 쓸모없는 빈 슬롯은 제작 완료 시 제거한다. 원본과 비교할 때는 완성 파츠와 참조를 번갈아 표시한다. Cubism 가져오기용 복사본에서는 참조 레이어를 삭제한다. RGB 8비트, sRGB를 기준으로 준비하고, 마스크·레이어 효과에 의존하는 모습은 가져오기용 복사본에서 파츠별 실제 픽셀로 정리한 뒤 외관을 비교한다. PSD 앱/Cubism에서의 실제 열기 검증은 아직 수행하지 않았다.

## 파츠별 분리와 복원

| 그룹 | 분리 대상 | 움직임을 위해 필요한 보완 |
|---|---|---|
| 얼굴 | 피부 베이스, 음영, 좌우 귀 | 눈·코·입을 떼어낸 자리는 피부로 복원. 이마는 앞머리 뒤, 얼굴은 옆머리 뒤까지 연장 |
| 눈 L/R | 위·아래 속눈썹, 위·아래 눈꺼풀 피부, 흰자, 홍채, 동공, 반사 | 홍채는 가려진 원형 영역까지 복원. 흰자는 시선 이동 범위를 덮도록 확장. 닫힌 눈 아래 피부를 확보 |
| 눈썹 | 좌우 독립 | 앞머리 뒤 끝부분까지 복원. 눈썹이 움직인 자리에는 피부가 남아야 함 |
| 코 | 원본 선, 원본 음영 | 원본에 없는 콧대 선을 만들지 않음. X/Y 움직임에 따라 위치와 음영을 작게 조정 |
| 입 | 상·하 입술, 상·하 경계선, 입안, 치아, 혀 | 입안·치아·혀는 원본에서 확인 불가. 별도 복원 그림 필요. 피부 베이스에 원래 입이 중복으로 남지 않도록 처리 |
| 앞머리 | 중앙 가닥, 좌우 큰 덩어리 | 가닥 사이가 벌어져도 구멍이 안 생기도록 뒤쪽 머리와 이마를 채움 |
| 옆머리 | 좌우 긴 가닥, 귀 뒤 가닥 | 뿌리 고정, 끝부분 변형. 얼굴 앞/귀 뒤를 통과하는 부분은 필요 시 별도 레이어 |
| 뒷머리·묶음머리 | 뒤통수 베이스, 좌우 뒷머리, 묶음과 접힌 덩어리, 잔가닥 | 상단이 잘려 전체 윤곽 미확인. 묶음은 단단한 질량으로, 잔가닥만 상대적으로 유연하게 |
| 목·몸통 | 목 피부·그림자, 몸통 | 목을 턱 안쪽과 의상 안쪽으로 연장. 몸통은 전체 원본 필요 |
| 후드 | 후면, 내부, 좌우 앞면, 좌우 테두리 | 목·어깨에 닿는 부위 고정. 후드 속과 접힘 아래 가려진 영역 복원 |
| 의상·팔 | 칼라, 앞판, 소매, 상완, 전완, 손 | 디자인 미확인. 어깨·팔꿈치 관절 겹침을 확보한 뒤 메시 설정 |
| 어깨장식 | 좌우 앞·뒤 장식 | 존재·모양 확인 후 확정. 고정부와 흔들리는 끝을 구분 |

복원 여유 폭은 일괄 픽셀값으로 정하지 않는다. 각 파츠가 최대 변형에서 이동하는 거리보다 충분히 넓게 채우고, 극단 키폼 조합에서 빈틈이 없는지 확인한다. 얼굴 선화와 머리카락 경계를 여러 레이어에 중복시키면 이중선이 생기므로 한쪽이 소유하도록 한다.

## 권장 디포머 구조

```text
Root
└─ Body_Z_Rotation
   └─ Body_XY_Warp
      ├─ Torso / Outfit / Arms / ShoulderOrnaments
      ├─ Hood_Warp → Hood_Physics_L/R
      ├─ Neck_Warp
      └─ Head_Z_Rotation (목 윗부분 기준)
         └─ Head_XY_Warp
            ├─ Face / Ears / Nose / Mouth_Form → Mouth_Open
            ├─ Brow_L/R_Warp
            ├─ Eye_L/R_Form → Eye_L/R_Blink
            │  └─ Gaze_L/R (Iris / Pupil / Highlight)
            └─ Hair_Root_* → Hair_Physics_* → Hair_Tip_*
```

눈의 시선 변형과 눈꺼풀 닫힘이 서로 찌그러뜨리지 않도록 역할을 분리한다. 홍채·동공·반사는 흰자 ArtMesh의 범위로 클리핑하고, 흰자 자체는 깜빡임에 맞춰 줄인다. 완전 닫힘에서는 흰자와 반사가 남지 않도록 필요 시 불투명도를 함께 제어한다. 후드는 머리보다 몸통의 움직임을 주로 따른다. 목 그림자는 턱 움직임에 맞춰 별도 보정한다.

## 파라미터와 키폼 계획

아래 범위는 제작 출발점이다. 고개·몸통 값은 Live2D 파라미터 값이며 실제 시각적 회전 각도를 보장하지 않는다. 이 작은 비정면 원본에서는 큰 회전보다 보존 가능한 작은 변형으로 시작한다.

| ID | 범위 / 기본값 | 키폼과 점검 |
|---|---|---|
| ParamEyeLOpen / ParamEyeROpen | 0~1 / 1 | 0, 0.5, 1. 눈꼬리는 유지하고 위 눈꺼풀이 주로 내려옴. 각각 윙크 검증 |
| ParamEyeBallX / ParamEyeBallY | -1~1 / 0 | X/Y 중앙·양끝 및 대각선. 홍채가 눈 바깥으로 새지 않도록 제한 |
| ParamBrowLY / ParamBrowRY | -1~1 / 0 | 상하 이동, 원본 두께 보존 |
| ParamBrowLAngle / ParamBrowRAngle | -1~1 / 0 | 회전 중심을 각 눈썹 안쪽 부근에서 조정 |
| ParamBrowLForm / ParamBrowRForm | -1~1 / 0 | 곡률 변화. 중립에서 원본 눈썹과 일치 |
| ParamMouthOpenY | 0~1 / 0 | 0, 0.3, 0.7, 1. 닫힘~열림. 원본의 미세한 입술 틈은 중립 디자인으로 보존 가능 |
| ParamMouthForm | -1~1 / 0 | 좁힘·기본·넓힘. OpenY와 3×4 조합을 확인. 두 축만으로 정확한 모든 발음을 보장하지 않음 |
| ParamAngleX / ParamAngleY | -30~30 / 0 | 각 축 3점 및 네 모서리, 합계 9 방향 보정. 코·귀·턱·가림 관계를 함께 조정 |
| ParamAngleZ | -30~30 / 0 | 목 위를 중심으로 기울임. 실제 외관은 먼저 작은 범위로 설정 |
| ParamBodyAngleX / Y / Z | -10~10 / 0 | 몸통 좌우·앞뒤·기울기. 전신 자료 확보 전 큰 움직임 보류 |
| ParamBreath | 0~1 / 0 | 선택 사항. 후드와 어깨가 아주 작게 함께 움직이도록 설정 |

깜빡임·립싱크 그룹에 각각 눈 열림과 입 열림 ID를 등록한다. 음량 기반 립싱크는 주로 `ParamMouthOpenY`를 구동하고, `ParamMouthForm`은 표정이나 지원되는 트래킹 입력에 연결한다. 원본 중립 입 모양과 대기 상태를 먼저 맞춘다.

## 물리 계획 — 사용자 정의 출력 ID

다음 `ParamPhys...`는 이 프로젝트에서 정의할 사용자 지정 파라미터다. 초기 범위는 -1~1, 기본값 0. 구체적인 물리 수치는 메시·크기·목표 프레임 환경에서 튜닝해야 하므로 현재 파일에는 실행 설정으로 넣지 않았다.

| 출력 ID | 입력 | 고정 위치 / 상대적 반응 |
|---|---|---|
| ParamPhysFrontL / R / C | AngleX, AngleZ | 가르마 뿌리 고정. 짧은 지연, 작은 진폭 |
| ParamPhysSideL / R | AngleX, AngleZ, BodyAngleX | 관자놀이 고정. 앞머리보다 큰 지연, 끝부분 위주 변형 |
| ParamPhysBack | AngleX, BodyAngleX | 뒤통수 고정. 중간 지연과 작은 진폭 |
| ParamPhysBun | AngleZ, AngleX | 묶인 위치 고정. 매우 작은 진폭, 묶음 형태 유지 |
| ParamPhysHoodL / R | BodyAngleX, BodyAngleZ | 목·어깨 접점 고정. 무거운 반응, 작은 진폭 |
| ParamPhysOrnamentL / R | BodyAngleX, BodyAngleZ | 실제 부착점 확인 뒤 설정. 단단한 장식은 회전 중심 위주 |

양쪽 머리카락은 동일 설정을 복제한 뒤 길이 차이에 따라 보정한다. 몸통→고개→머리카락으로 전달되는 흐름을 확인하고, 물리 출력이 자기 입력에 다시 들어가는 구조는 피한다. 머리·후드 교차는 자동 충돌 해결을 기대하지 말고 출력 범위와 키폼으로 제어한다. 정지 후 잔떨림이 사라져야 한다.

## 제작 순서와 통과 기준

1. 잘리지 않은 고해상도 원본 또는 기존 레이어 PSD 확보. 상단 묶음머리·양쪽 어깨·몸통·팔 확인. 현재 스냅샷으로 확인 불가능한 부분을 표시한 상태 유지.
2. 원본 외곽을 바꾸지 않고 파츠를 분리하고 가려진 영역을 복원. 각 슬롯에 실제 그림을 넣는다.
3. 파츠 재합성의 중립 외관을 원본과 비교. 얼굴 폭·턱선·눈매·머리 외곽·후드 색이 바뀌면 리깅 전에 수정.
4. 눈 깜빡임·시선·입부터 메시와 키폼 설정. 눈꼬리, 속눈썹, 입꼬리 주변은 형태를 잡을 수 있게 배치하되 과도하게 잘게 나누지 않음.
5. 고개 XYZ와 몸통 설정. 대각선 고개+시선 끝+반쯤 감긴 눈, 고개 아래+열린 입 조합까지 점검.
6. 마지막에 물리 추가. 가닥 뿌리 미끄러짐, 후드 뚫림, 목 틈, 장식 분리 여부 확인.
7. Cubism에서 저장·내보내기 후 사용하는 트래킹 앱에서 깜빡임, 음성, 기본 자세, 물리 안정성을 실제 검증.

현재 검증 범위는 PSD 합성 이미지가 원본 픽셀과 같은지, 레이어 이름이 중복되지 않는지의 파일 수준 확인이다. 실제 파츠 리깅이나 Cubism 실행 검증을 대신하지 않는다.
