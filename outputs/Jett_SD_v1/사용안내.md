# 제트 SD 간단 아바타

`index.html`을 브라우저로 열거나 https://move123321.github.io/jett/sd/ 에 접속하세요.

- 자동 깜빡임과 작은 몸 흔들림이 기본으로 켜집니다.
- ‘말하기 미리보기’로 입 움직임을 확인합니다.
- ‘마이크 켜기’를 직접 누르고 권한을 허용하면 음량에 따라 입을 여닫습니다. 음성은 저장하거나 서버로 전송하지 않습니다.
- ‘캐릭터만 보기’로 조작부를 숨기고 Esc로 돌아옵니다. `?overlay=1`을 주소 끝에 붙이면 투명 배경 표시 모드로 시작합니다.
- PNG 네 장은 기본, 눈 감음, 말하기, 눈 감고 말하기 상태입니다.
- PSD는 이 네 상태를 각각 완전한 그림 레이어로 담은 편집용 파일입니다. 기본 레이어만 표시되어 있습니다.

이 버전은 복잡한 작업을 줄이기 위한 이미지 전환형(PNG 아바타)입니다. 얼굴 추적, 독립된 눈동자 이동, 머리카락 물리, Cubism 리깅 및 .moc3 파일은 포함되지 않습니다. 기존 Live2D 작업은 그대로 남아 있습니다.

표정 이미지는 내장 이미지 생성 도구로 만들었습니다. 상태 간 작은 그림 차이가 있을 수 있습니다. 실제 마이크 장치 권한 승인은 사용자가 직접 해야 합니다.
