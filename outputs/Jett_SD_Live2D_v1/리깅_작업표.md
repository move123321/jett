# SD 제트 Cubism 파츠 준비

## 상태

`Jett_SD_parts.psd`는 29개 개별 레이어를 가진 파츠 분리 초안입니다. 기존 4장 표정 전환 PSD와 다릅니다. 기본 자세의 불투명 픽셀은 SD 원화와 일치하며, 반투명 경계의 재합성에는 최대 1/255의 색상 반올림 차이가 있습니다. 얼굴 보완 이미지만 내장 이미지 생성 도구로 추가 제작했습니다.

아직 Cubism에 가져오기 검증, 메시 정리, 디포머 구성, 파라미터 키 연결, 물리 설정과 `.cmo3`/`.moc3` 저장이 완료되지 않았습니다. 본 파일을 완성 리깅으로 간주하지 마세요.

## 레이어 구성

- 몸: Body_Base, Arm_R/L, Leg_R/L, Hood, Neck
- 머리: Head_Base, Hair_Back, Hair_Bun, Hair_Front_R/L/Center, Hair_Side_R/L
- 얼굴: Brow_R/L, Eye_R/L_White, Eye_R/L_Iris, Eye_R/L_Lash, Nose, Mouth_Closed
- 보완: Restore_FacialSkin
- 숨겨진 대체형: Eye_R/L_Closed, Mouth_Open

R은 캐릭터의 오른쪽(화면 왼쪽), L은 캐릭터의 왼쪽입니다. 작은 눈썹/눈/입 레이어는 경계 주변 피부를 일부 포함합니다. 머리 및 팔 연결부의 가려진 부분 전체는 복원되지 않았으므로 큰 회전 전에 추가 보완이 필요합니다. 눈 흰자 레이어에는 홍채가 차지하던 구멍이 있으므로 시선 XY를 설정하기 전에 전체 흰자를 복원해야 합니다. 얼굴 보완 레이어는 이 구멍을 대신할 눈 흰자가 아닙니다.

## Cubism 작업 순서

1. PSD로 새 모델을 생성하고 `Jett_SD_rig.cmo3`로 저장합니다.
2. 표시된 파츠에 자동 메시를 만든 뒤 눈, 입, 머리 경계를 수동 확인합니다. 숨겨진 대체형 3개도 메시가 필요합니다.
3. 몸 회전 디포머 아래 몸 전체를 배치하고, 목 근처에 머리 회전 디포머를 만듭니다. 머리 디포머 아래 머리카락·얼굴·얼굴 보완·눈·입을 넣습니다. 팔과 머리카락은 각각 별도 디포머를 사용합니다.
4. 최소 기능은 눈 깜빡임, 입 열림, 고개 Z입니다. 먼저 이 기능들을 저장·확인한 뒤 XY 변형과 물리를 추가합니다.

| 파라미터 | 키값 | 연결 및 검토 |
|---|---|---|
| ParamEyeROpen / ParamEyeLOpen | 0, 1 | 1에서 흰자·홍채·속눈썹 표시, 0에서 닫힌 눈 대체형 표시. 단순 전환을 먼저 확인한 뒤 중간 키에서 찌그러짐 없이 세로 변형 정리 |
| ParamMouthOpenY | 0, 1 | 0에서 Mouth_Closed, 1에서 Mouth_Open. 얼굴 피부 패치 경계와 중복 입술 확인 |
| ParamAngleZ | -15, 0, 15 | 머리 회전 디포머, 목 연결부 기준. ±15도는 목표 범위이며 외곽 빈 부분 검토 후 축소 가능 |
| ParamBodyAngleZ | -5, 0, 5 | 몸 전체 회전, 발 근처 피벗 |
| ParamEyeBallX/Y | -1, 0, 1 | 흰자 복원 및 홍채 클리핑을 마친 후 연결 |
| ParamAngleX/Y | -10, 0, 10 | 머리 워프 디포머, 얼굴 원근과 뒷머리 복원 후 연결 |
| ParamBrowRY / ParamBrowLY | -1, 0, 1 | 눈썹 독립 이동, 피부 패치 이음새 확인 |
| ParamHairFront / ParamHairSide / ParamHairBun | -1, 0, 1 | 앞머리·옆머리·묶음머리 디포머. 붙어 있는 머리 경계가 벌어지지 않게 작은 범위로 시작 |

후드 물리는 고개와 몸 키 검증 후 추가합니다. 물리 입력은 AngleX/BodyAngleZ를 작은 비율로 연결하고, 출력은 해당 머리/후드 전용 파라미터로 설정합니다. 최종적으로 텍스처 아틀라스를 만든 다음 모델 내보내기를 진행합니다.
